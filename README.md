# Nightlife App

This is an Android application for a nightlife and event management platform.

## Features

- User authentication (sign up and login)
- Club listing and reservation
- QR code generation for reservations
- Club dashboard for managing reservations
- QR code scanning for validating reservations

## How to Run

1.  Clone the repository.
2.  Open the project in Android Studio.
3.  Replace the placeholder `google-services.json` with your own Firebase project's `google-services.json` file.
4.  Run the application on an Android device or emulator.
